今回の変更について確認した内容
・Actor + Test → ATest。プレビュー、実ファイル、コンストラクタ、include の一致
・全テンプレートの自動接頭辞と、正しい接頭辞を入力済みの場合の二重付与防止
・入力欄はフォーカス移動・生成・型の変更でも書き換えない
・型の変更で Test の生成名だけ ATest / UTest / FTest / ETest / ITest に変わる
・Animation / Enemy などの通常名、数字・_ を伴う接頭辞、予約名、最終文字数制限
・Interface の U / I ペア、生成ファイル名と generated.h の一致
・基本名と接頭辞付き名に共通の重複検出、追記先の重複宣言防止
・モジュール欄の＋メニューから、モジュール・プラグインを実際に追加
・モジュール追加後も、入力中の型・名前・オプションを保持
・C++未導入のプロジェクトへの最初のモジュールと Target.cs の追加
・既存のコンテンツ用プラグインへの最初の C++ モジュール追加
・入れ子のプラグイン検出、既存プラグインの選択、Editorモジュールの登録
・既存ディスクリプタの独自フィールド保持、重複登録防止、有効化
・設定ファイルを読み取った同じバイト列を保存前の競合検査に使うこと
・フォルダだけの作成。4配置、複数階層、日本語名、プラグイン内フォルダ
・Public / Private 両側の空フォルダ作成。ダミーファイルを作らないこと
・作成後にフォルダを選択し、候補一覧とプレビューが更新されること
・既存フォルダを変更せず選択すること、キャンセル時に書き込まないこと
・不正パス、予約名、シンボリックリンク、同名ファイルの拒否
・フォルダ作成途中のエラー時に、作成済みの新しいフォルダを復元すること
・空フォルダ追加の取り消し、既存フォルダの保持、取り消し途中の失敗時の復元
・外部で追加されたファイル・フォルダがある場合は取り消さないこと
・生成、追加操作のモーダル制御と処理中の無効化
・CLI用ファイルを配布物へ再導入していないこと
