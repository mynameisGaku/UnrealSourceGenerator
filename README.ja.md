# [UnrealSourceGenerator](https://github.com/mynameisGaku/UnrealSourceGenerator)

[English](README.md) | 日本語

Unreal Engine のクラス・構造体・列挙型・インターフェースを生成する、独立した GUI ツールです。ヘッダーを `Public`、ソースを `Private` に分けるか、同じフォルダにまとめるかを選べます。

## 起動

**Python 3.10 以上と tkinter** が必要です。追加パッケージは不要です。
リポジトリ全体を取得し、Windows で **`gui.bat`** をダブルクリックしてください。
初期表示は英語です。右上で **日本語** に切り替えられ、選択は次回も維持されます。

## 生成

**プロジェクト（.uproject）→ モジュール → 型 → 名前**を選び、**フォルダ・配置**を指定して、プレビューを確認し**生成**を押します。追加の設定は**詳細設定…**、各項目の説明はツールチップで確認できます。

**型名には接頭辞を付け、ファイル名には付けません。** Actor で `PlayerBase` または `APlayerBase` と入力すると、クラス `APlayerBase` を次のファイルに生成します。

```text
Source/MyGame/Public/PlayerBase.h
Source/MyGame/Private/PlayerBase.cpp
```

`U`・`F`・`E`、インターフェースの `I` / `U` も同様です。`PlainClass` は入力どおりです。構造体・列挙型・インターフェースはヘッダーのみを生成します。既存ファイルの自動リネームは行いません。

## その他の操作

| 操作 | 場所 |
| --- | --- |
| モジュール・プラグインの追加、既存プラグインへのモジュール追加 | モジュール欄の **＋** |
| 空フォルダの追加 | フォルダ欄の **＋** |
| IDE 用プロジェクトファイルの更新 | **ツール → プロジェクトファイルを更新** |
| 生成ログ・UE の出力の表示、コピー・消去 | 下部の **▸ ログ**（起動時は閉じています） |
| 直前の生成・追加の取り消し | **ツール → 直前の操作を取り消す** |

プロジェクトファイルの更新には、Windows と対象の Unreal Engine が必要です。C++ のビルドは行いません。**詳細設定… → 生成後にプロジェクトファイルを更新**で自動更新もできます。

既存ファイルの変更前に確認し、`Saved/UnrealSourceGenerator/Backups` にバックアップします。生成後に編集されたファイルは取り消しで上書きしません。ログと取り消し履歴はアプリを閉じるまで保持します。

**ショートカット：** Ctrl+Enter / Ctrl+G — 生成、F5 — プロジェクトの再読み込み。

Windows 実機での起動と Unreal Engine / UHT によるビルドは未検証です。[テスト詳細](docs/TESTING.md)。
