# UnrealSourceGenerator

[English](README.md) | 日本語

Unreal Engine 向けの GUI 専用 C++ ソース生成ツールです。クラス・Component・Subsystem・構造体・列挙型・Interface・プレーン C++ 型に対応。コードをプレビューし、`.h` を `Public`、`.cpp` を `Private` に分けて、または同じフォルダに生成できます。

## 導入

**Python 3.10 以上と tkinter** が必要です。追加パッケージは不要。リポジトリ全体を取得し、フォルダ構成を保ったまま **`gui.bat`** をダブルクリックします（Windows）。Unreal Editor の起動は不要です。

初期表示は **English**。右上から **日本語** に切り替えられ、次回起動時も維持します。

## 使い方

1. **プロジェクト**で `.uproject` を選びます。
2. **モジュール**と**型**を選び、**名前**を接頭辞なしで入力します。
3. **フォルダ**と**配置**を指定します。
4. **プレビュー**を確認し、**生成**を押します。

Actor の `Test` は `ATest.h` / `ATest.cpp` になります。`ATest` と入力済みなら二重に付けません。UObject 系は `U`、構造体は `F`、列挙型は `E` を付け、PlainClass は入力どおりです。

モジュール `MyGame`、フォルダ `Actors`、配置 `Public / Private` の場合：

```text
Source/MyGame/Public/Actors/ATest.h
Source/MyGame/Private/Actors/ATest.cpp
```

フォルダは `AI/Movement` のような階層も指定できます。配置は **同じフォルダ・Private のみ・Public のみ** も選べます。

## 追加・詳細設定

- **モジュール横の＋**：Runtime / Editor モジュールやプラグインを追加します。新規プラグインには同名の C++ モジュールも作成。既存プラグインへの追加は**生成先**で選びます。モジュールがない場合は、先に Runtime モジュールを追加してください。
- **フォルダ横の＋**：空フォルダを追加します。Public / Private では両側に同じ階層を作成します。
- **詳細設定…**：生成する関数、構造体の補助機能、プレーン C++ 型の名前空間、既存ヘッダーへの追記などを設定します。Tick は初期状態で無効。項目にマウスを合わせるか **F1** で説明を表示します。

## プロジェクトファイル・ログ

**ツール → プロジェクトファイルを更新**で IDE 用ファイルを更新します。C++ のビルドは行いません。Windows と対象の Unreal Engine が必要です。自動実行は**詳細設定… → 生成後にプロジェクトファイルを更新**で有効にします。

左下の **▸ ログ**で開閉します。**起動時は毎回閉じた状態**で、閉じている間も記録し、勝手に開くことはありません。

ソース生成、ファイル変更、モジュール・プラグイン・フォルダ追加、取り消し結果、エラーを表示します。UE のプロジェクトファイル更新では、標準出力・エラー出力を処理中から表示し、コマンド・終了コード・処理時間も記録します。

**コピー／消去**に対応。上へスクロールすると自動追従を止めます。履歴は起動中のみ保持するため、必要なログは終了前にコピーしてください。UE の出力は原文のままです。

## バックアップ・取り消し

既存ファイルは変更前に確認し、プロジェクト内の `Saved/CppSourceGenerator/Backups` にバックアップします。**ツール → 直前の操作を取り消す**で、直前の生成・追加を戻せます。生成後の編集を上書きせず、追加フォルダに別の内容が入った場合も削除しません。取り消し履歴は起動中のみ、バックアップは終了後も残ります。

## 注意事項

**Ctrl+Enter / Ctrl+G**：生成。**F5**：プロジェクトを再読み込み。

`EditorSubsystem` は Editor モジュールを選んでください。Windows 実機での起動と、Unreal Engine / UHT による生成コードのビルドは未検証です。
